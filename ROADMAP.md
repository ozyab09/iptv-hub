# ROADMAP — IPTV Hub

> История изменений — в git; актуальный план — здесь.

## v0.1 — MVP (текущая)

- [x] Экран настройки: URL плейлиста + EPG, сохранение в localStorage
- [x] GET-параметры `?p=&e=` с приоритетом над localStorage
- [x] Парсер M3U: атрибуты, дедуп по URL, сортировка, категории
- [x] Нормализация имён (эмодзи/quality/регионы) — общая для поиска и EPG
- [x] EPG: XMLTV (plain + gzip), now/next в списке каналов
- [x] Плеер: hls.js + нативный fallback, bottom-bar + театральный режим
- [x] Поиск по названию и категории
- [x] Тёмная неоновая тема, mobile-first
- [x] Vitest: парсеры (~20 тестов)
- [x] CI: тест + сборка; деплой на Pages из main

## v0.2 — Удобства (текущая)

- [x] PWA: manifest + service worker (shell cache-first, плейлист/EPG
      network-first с оффлайн-fallback, медиа не кешируется)
- [x] Иконки PWA генерируются скриптом без зависимостей (`npm run icons`)
- [ ] Избранное (localStorage, ⭐ в списке, секция сверху)
- [ ] Модалка полной программы канала (день из EPG)
- [ ] Обработка ошибок потока с retry-кнопкой в player bar
- [ ] Экспорт/импорт настроек JSON

## v0.3 — Больше форматов

- [ ] DASH-адаптер (dash.js) за проверкой формата
- [ ] Поддержка `#EXTVLCOPT` user-agent/referrer для hls.js (xhrSetup)
- [ ] Fuzzy-матчинг EPG по имени (Levenshtein ≤ 2, как в родительском iptv)

## v1.0 — Полировка

- [ ] Скринридер-аудит (aria-live для тостов, фокус-менеджмент в модалках)
- [ ] Локализация en/ru
- [ ] Тесты на UI-логику (jsdom) — рендер списков, фильтры
- [ ] Опционально: Android TV-компаньон (Kotlin, WebView на этот же сайт)
