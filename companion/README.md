# IPTV Hub Companion

Локальный помощник для http-плейлистов (#452) и данных без CORS (#465). Сайт
IPTV Hub на GitHub Pages открывается по https, поэтому браузер блокирует
http-плейлисты и потоки (mixed content), а ответы провайдера без
CORS-заголовков (плейлист, телепрограмма) не может прочитать вовсе. Компаньон
слушает **только 127.0.0.1**, сам загружает такие ресурсы и отдаёт их сайту.
Внешних серверов нет, ссылки не покидают устройство и не записываются в логи.

## Запуск

Скачайте бинарник для своей ОС из GitHub Releases и запустите. Значок
появится в трее; при первом запуске включается автозапуск при входе в
систему (галочка в меню трея). Бинарники не подписаны:

- Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае»;
- macOS: правый клик → «Открыть» при первом запуске;
- Linux: `chmod +x` и запуск.

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-port` | `47800` | порт на 127.0.0.1 (его ищет сайт) |
| `-background` | выкл. | не открывать сайт (так запускает автозапуск) |
| `-headless` | выкл. | без трея и без автозапуска (серверы, отладка) |
| `-origin` | — | дополнительный разрешённый сайт, например `http://localhost:5173` |

## Протокол

- `GET /health` → `{"app":"iptv-hub-companion","version":"…","protocol":1}`.
- `GET /pair` → `{"token","proxyBase","protocol"}` — только для разрешённого `Origin`.
- `GET|HEAD /proxy/<token>/<scheme>/<authority><path>?<query>` — загрузка
  http(s)-ресурса. HLS-плейлисты переписываются (сегменты, варианты, `URI="…"`
  идут через прокси), списки каналов M3U — нет. `Range`/206 и статус
  провайдера передаются как есть; байты — без изменений (провайдеру всегда
  отправляется `Accept-Encoding: identity`).

## Безопасность

- Слушает только `127.0.0.1`.
- Чужие сайты получают 403: CORS и `/pair` только для `https://ozyab09.github.io`
  (и сайтов из `-origin`); ответ на preflight Private Network Access.
- `/proxy/` требует случайный токен из `config.json` (каталог настроек
  пользователя, права 0600) — иначе `<video>`/`<img>` чужой вкладки сделали бы
  компаньон открытым relay.
- Адреса назначения в loopback, приватных сетях, link-local и CGNAT
  запрещены уже после DNS-разрешения (защита от SSRF и DNS rebinding).
- Только http/https, не больше 5 редиректов, URL не логируются.

## Разработка

```sh
cd companion
go test ./...
GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H windowsgui -X main.version=dev" -o iptv-hub-companion.exe .
```

macOS-сборка требует cgo (трей) и собирается на macOS.
