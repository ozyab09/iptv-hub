Плеер

Применяются к следующему запуску канала. Буфер: 5–600 с, диагностика: 1–60 с. Больший буфер требует больше памяти; доступная пауза зависит от потока. Низкая задержка работает с поддерживающими её HLS-потоками.

Для HLS в Auto. Если тип сети неизвестен, ограничение включается для медленного соединения 2G/3G. Ручной выбор качества имеет приоритет; если нет уровня ниже порога, используется самый низкий доступный.

Браузер не сообщает тип сети — автоматическое ограничение качества недоступно.

Обновление плейлиста

Проверять

Список перечитывается из сети по расписанию; о результатах сообщит колокольчик.

Имена и скрытие каналов

Вернёт исходные имена и покажет скрытые каналы. Избранное сохраняется.

Проблемные каналы

Метка появляется после окончательной ошибки подключения и снимается, когда канал успешно заиграет. Ошибки архива и записей не учитываются.

Родительский PIN

PIN запрашивается при входе в группу и запуске каждого её канала. Забытый PIN можно удалить только очисткой всех данных сайта в браузере.

Группы каналов

Выключите группу, чтобы скрыть её каналы. Стрелки меняют порядок категорий текущего плейлиста. Избранное и записи сохраняются.

Резервная копия

Файл хранит плейлисты, избранное и тему — удобно перенести на другое устройство.

Как это работает
  • Приложение — статика (GitHub Pages), бэкенда нет.
  • Плейлистов может быть несколько — переключение в шапке.
  • Избранное у каждого плейлиста своё. При обновлении со старой версии общее избранное переносится первому плейлисту.
  • На бакете должен быть включён CORS (см. README).
