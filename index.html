Self-hosted плеер для ваших плейлистов. Ссылки хранятся только в этом браузере.

Как это работает
  • Приложение — статика (GitHub Pages), бэкенда нет.
  • Плейлистов может быть несколько — переключение в шапке.
  • Избранное у каждого плейлиста своё.
  • На бакете должен быть включён CORS (см. README).
